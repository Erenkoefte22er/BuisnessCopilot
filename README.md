# Business Copilot

Business Copilot is a business analytics application built with Python and Streamlit.

The platform transforms CSV and Excel data into structured dashboards, key performance indicators and business insights.

## Current Features

- CSV and Excel import
- Interactive analytics dashboard
- Automatic detection of numerical metrics
- Business metric recognition
- Revenue, cost and profit analysis
- Profit margin calculation
- Product and category analysis
- Interactive charts
- Data quality analysis
- Missing value detection
- Duplicate detection
- Dataset filtering
- CSV exports
- Demo workspace

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Project Status

Business Copilot is currently under active development.

Planned features include:
